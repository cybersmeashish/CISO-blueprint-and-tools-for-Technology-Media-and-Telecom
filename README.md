# CISO blueprint and tools for — Technology, Media & Telecom (TMT)

By [Ashish Srivastava](https://github.com/cybersmeashish).

A structured home for industry security blueprints, practical tools, original research and traceable evidence. This repository follows the user-defined industry taxonomy.

**Stage:** sector folders initialized. Across the seven-repository portfolio, BFSI and Oil & Gas retain their existing migrated reference content; other sector blueprints/tools are future contributions. Folder coverage does not assert client engagements, deployment, accreditation or regulatory conclusions.
